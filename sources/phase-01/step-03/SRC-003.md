# SRC-003 — OECD Learning Compass 2030

**Title:** *The OECD Learning Compass 2030*  
**Publisher:** Organisation for Economic Co-operation and Development (OECD)  
**Canonical URL:** https://www.oecd.org/en/data/tools/oecd-learning-compass-2030.html  
**Status:** Referenced

## Step 3 relevance

Provides an aspirational framework connecting future-oriented education with student agency, well-being, and knowledge, skills, attitudes, and values. The OECD states that the framework is globally informed and intended for local contextualisation.

## Use

Use it as an example of how an international institution organizes future-oriented educational aims and competencies.

## Caution

The framework is aspirational and evolving. Its existence does not demonstrate that each component has equal priority in every country or that implementing the framework automatically produces better outcomes.
