# SRC-031 — Hong et al., Mixed Methods Appraisal Tool (MMAT)

**Title:** “The Mixed Methods Appraisal Tool (MMAT) version 2018 for information professionals and researchers”  
**Authors:** Quan Nha Hong et al.  
**Publication:** *Education for Information*, 2018  
**DOI:** https://doi.org/10.3233/EFI-180221  
**Type:** Peer-reviewed appraisal-tool article

## Contribution
Describes the 2018 MMAT for critically appraising qualitative, randomized, non-randomized, quantitative descriptive, and mixed-methods studies.

## Use
Consider MMAT when an evidence set includes several empirical designs and a structured appraisal aid is useful.

## Limits
It does not remove the need for design-specific judgement and should not be treated as an automatic ranking or universal score.
