# Sources

This directory is the source archive for the Soren Education System research.

## Source-of-truth hierarchy

1. **Primary source documents** — official reports, laws, policies, datasets, peer-reviewed research, and original research instruments.
2. **Source metadata** — bibliographic record, canonical URL, publication date, version, access date, and archival status.
3. **Evidence notes** — carefully bounded notes extracted from primary sources, with page/section references where available.
4. **Synthesis** — our interpretation of multiple sources.
5. **Design proposals** — recommendations for the proposed education system.

A synthesis or proposal must never silently replace the underlying source.

## Archival rule

When licensing, access, and tooling permit, the original document should be stored under `sources/documents/` with a stable filename.

When a document cannot be archived directly, the repository must still retain:
- canonical official URL;
- publication/version information;
- access date;
- source type;
- why it matters;
- archival status;
- a source-specific evidence note.

The canonical external document remains authoritative until an archival copy is added.

## Phase mapping

- `sources/phase-01/` — sources primarily supporting Phase 1 / Step 1.
- `sources/phase-02/` — sources primarily supporting Phase 2, etc.
- Cross-phase sources remain in the phase where they are first introduced and are cross-referenced elsewhere.

## Integrity rule

We do not collect sources merely because they support a preferred conclusion. Sources that challenge, qualify, or contradict our emerging model are equally important and must be retained.
