# SRC-053 — Small Class Sizes for Improving Student Achievement

- **Authors:** Trine Filges, Christoffer Scavenius Sonne-Schmidt, Bjørn Christian Viinholt Nielsen
- **Journal:** *Campbell Systematic Reviews*, 14(1)
- **Publication:** 11 October 2018
- **DOI:** https://doi.org/10.4073/csr.2018.10
- **Open full text:** https://pmc.ncbi.nlm.nih.gov/articles/PMC8428040/
- **Language:** English
- **Type:** Systematic review
- **Scope:** K–12 general education; review included 127 studies (148 papers) across 41 countries, but only ten studies entered the meta-analysis.
- **Relevant claims:** Effects of class-size reduction on academic achievement.
- **Appraisal:** Demonstrates why policy claims about class size need to examine design, intervention, and cost. The difference between the broad review set and the smaller meta-analysis must be stated.
- **Limits:** Results are not a blanket proof that class size never matters or that reducing it is always the best investment. Context and teacher practices matter; Bangladesh transfer needs appraisal.
- **Status:** Identified; detailed results and applicability appraisal pending.
