# Research Decisions

This directory records decisions that affect the research itself—not just presentation preferences.

Decision records should state the decision, date/status, rationale, evidence and counterevidence, value premises where relevant, expected outcome, failure mode, and revisit condition.

Examples include scope changes, operational definitions, inclusion/exclusion rules, evidence thresholds, source-quality rules, unresolved disagreements, rejected hypotheses, and major revisions to the research question.
