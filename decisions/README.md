# Research Decisions

This directory records decisions that affect the research itself.

Examples:

- scope changes;
- inclusion/exclusion rules;
- definitions adopted;
- evidence thresholds;
- source-quality rules;
- unresolved disagreements;
- rejected hypotheses;
- major revisions to the research question.

A decision is not the same thing as a design preference. Decisions should include rationale and, where relevant, the evidence that caused the decision.
